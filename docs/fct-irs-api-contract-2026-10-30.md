# FCT-IRS public API contract check

Production was read only on 30 October 2026. The combined service `tax-id-tin-generation-or-retrieval` remains publicly visible as “Tax ID/TIN generation or retrieval”, with one free, verified fee option, one FCT-IRS FAQ source and a generic `https://fctirs.gov.ng/` website channel. The live response exposes numeric service, fee, source and channel IDs. Its fee option has no `sources` array; the FAQ is present only in the service-level list. The FAQ excerpt overstates support for retrieval as free. This is not a correction of the production evidence record.

The local API was tested against an isolated temporary PostgreSQL database containing a copy of that previously observed public record. It returns the same slug, free model, verified status and channel without numeric IDs; the FAQ is nested in the fee option and retained in the compatibility service-level list. `sourceType` remains a machine-readable compatibility field and `sourceTypeLabel` is a human-readable label. Current fee status counts in `verificationSummary` are public aggregate counts, not the private verification event narrative. Event summaries, investigator notes and audit metadata are not selected for public output.

The local source register obtains its `associations` from current fee-source links to active services and MDAs. Associations provide public MDA and service slugs, names and linked fee status. The UI filters these associations and links to service slugs; it no longer joins on numeric source IDs or substitutes a historical source-register snapshot. Sources have no public slug in the data model; no new source identifier is needed for these self-contained records, so no schema or unstable URL-derived identity was introduced. The page fetches all source pages and uses the API's count. Source list ordering uses an internal ID as a server-side tie-breaker, but does not return it.

Local terminal checks exercised stats, MDA list and detail, MDA service list, combined service detail, sources and search. This isolated snapshot cannot establish the state of production audit history or verify replacement records. It also does not verify FCT-IRS retrieval pricing. NIMC date-of-birth modification remains excluded and unchanged.

A public narrative verification summary requires a separate governed data-model and publishing decision. Existing verification-event summaries have no explicit public-approval marker and remain private. The generic panel relies on structured public fee and source fields; no FCT-specific evidence wording is hardcoded.
